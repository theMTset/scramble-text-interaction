# Project guidance

This repository owns the reusable ScrambleText React component and its demo.

- Keep `src/ScrambleText.tsx` dependency-free beyond React.
- Preserve mouse, touch, accessibility, and reduced-motion behavior together.
- Run `npm run typecheck` and `npm run build` before committing code changes.
- Keep the Turbopuffer reference framed as inspiration from its public wordmark; do not imply affiliation.
- Do not add adoption conditions that conflict with the 0BSD license.
